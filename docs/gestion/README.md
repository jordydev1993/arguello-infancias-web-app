# Gestión del proyecto

Planificación Scrum del proyecto Argüello Infancias (web + mobile), iniciado el 12/03/2026
por el equipo de analistas: Jordy, Meli, Cami y Sofi.

| Archivo | Contenido |
|---|---|
| [`SPRINTS.md`](./SPRINTS.md) | Supuestos, roles, resumen de los 19 sprints, tareas por sprint y carga por integrante |
| [`GANTT.md`](./GANTT.md) | Diagrama de Gantt general y uno por integrante (Mermaid, GitHub lo dibuja) |
| [`Planificacion-Sprints-Gantt.xlsx`](./Planificacion-Sprints-Gantt.xlsx) | Planilla editable: backlog, sprints, carga y Gantt con fórmulas |

Los tiempos son una estimación realista para estudiantes de 3er año con 12 h/semana por
integrante, sprints de 2 semanas, receso invernal y capacidad reducida en semanas de parciales.
